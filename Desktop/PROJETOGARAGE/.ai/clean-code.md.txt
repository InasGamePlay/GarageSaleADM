Clean Code Skill, objetivo: gerar código limpo, legível, reutilizável e fácil de manter. Princípios: escreva código simples. Evite complexidade desnecessária. Evite duplicação (DRY). Mantenha cada função com uma única responsabilidade (SRP). Utilize nomes claros e descritivos. Prefira composição em vez de herança quando fizer sentido. Separe responsabilidades por módulos. Funções pequenas, objetivas, reutilizáveis, baixo acoplamento e alta coesão. Boas práticas: não crie código morto, não deixe comentários desnecessários, não use variáveis sem uso, evite números mágicos, utilize constantes quando necessário, evite aninhamentos profundos. Qualidade: revisar legibilidade, performance, segurança, organização e reutilização antes de finalizar. Resultado esperado, entregar código pronto para produção, consistente, de fácil manutenção.
