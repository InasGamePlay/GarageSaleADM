Performance Skill, objetivo, gerar código otimizado, rápido, escalável e eficiente por padrão. Prioridades:1. Reduzir processamento. 2. Reduzir consumo de memória. 3. Reduzir requisições desnecessárias. 4. Melhorar tempo de carregamento. 5. Melhorar experiência do usuário. Front-end: evite re-renderizações desnecessárias, use lazy loading quando apropriado, faça code splitting, utilize memoização somente quando houver benefício real, otimize imagens, evite JavaScript desnecessário, minimize o tamanho dos bundles e prefira CSS eficiente. Back-end: evite consultas repetidas ao banco, use paginação quando necessário, evite loops desnecessários, utilize cache quando apropriado, faça consultas otimizadas e evite operações bloqueantes. APIs: retorne apenas os dados necessários, evite múltiplas chamadas quando uma resolve, use paginação e filtros, padronize respostas e trate erros corretamente. Banco de dados: use índices quando apropriado, evite consultas N+1, selecione apenas colunas necessárias, evite consultas duplicadas e use transações quando necessário. Qualidade: antes de finalizar, revisar consumo de memória, tempo de execução e escalabilidade, eliminando gargalos óbvios. Resultado: entregar soluções rápidas, escaláveis e eficientes, prontas para produção.
