React Skill, objetivo, gerar aplicações React modernas, performáticas, organizadas e fáceis de manter. Princípios: utilize componentes funcionais. Utilize hooks em vez de classes. Mantenha componentes pequenos e reutilizáveis. Separe lógica de apresentação. Evite duplicação de código. Estrutura: organize o projeto com pastas como components, pages, hooks, services, contexts, utils, types e assets, quando aplicável. Componentes: cada componente deve ter apenas uma responsabilidade, receber só as props necessárias, evitar componentes gigantes e reutilizar existentes antes de criar novos. Estado: utilize estado local quando for suficiente, evite estado global desnecessário, derive valores em vez de duplicá-los e evite atualizações de estado em excesso. Hooks respeite as regras dos hooks, não chame hooks dentro de condicionais ou loops, crie hooks customizados para reutilizar lógica e utilize useEffect apenas quando for realmente necessário. Performance, evite renderizações desnecessárias, faça lazy-loading de componentes pesados, divida código em módulos quando apropriado. Revisão, antes de finalizar verifique legibilidade, reutilização, acessibilidade, performance e tratamento de erros. Resultado entregas React organizadas, escaláveis, performáticas, acessíveis e prontas para produção, seguindo as práticas atuais do ecossistema React.
