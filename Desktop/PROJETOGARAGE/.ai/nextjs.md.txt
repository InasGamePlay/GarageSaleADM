Objetivo, gerar aplicações Next.js modernas, rápidas, escaláveis e prontas para produção, seguindo as melhores práticas do framework. Princípios, utilize App Router como padrão, prefira server components, utilize client components somente quando necessário, priorize performance, SEO, acessibilidade, segurança e código limpo e reutilizável. Estrutura recomendada, app, components, hooks, services, lib, utils, types, styles e public. Organize componentes por responsabilidade, evite componentes gigantes e reutilize o que já existe. Server components, priorize busca de dados no servidor, reduza JavaScript enviado ao cliente e melhore o tempo de carregamento. Client components, utilize apenas para estado e interações quando realmente necessário. Data fetching, busque dados no servidor por padrão, evite chamadas duplicadas, use cache quando fizer sentido e escolha corretamente entre renderização estática, dinâmica ou incremental. Performance, use next/image para imagens, next/link para navegação, lazy loading quando apropriado, reduza o tamanho do bundle, evite bibliotecas pesadas e otimize fontes, scripts e imagens. SEO, sempre configure title, description, metadata, Open Graph, Twitter Cards e URLs amigáveis, usando HTML semântico. Segurança, nunca exponha variáveis de ambiente sensíveis, valide todas as entradas, sanitize dados, proteja rotas privadas e trate erros sem expor informações internas. Qualidade, revise performance, SEO, acessibilidade, segurança e reutilização antes de finalizar. Boas práticas, utilize TypeScript quando disponível, evite código duplicado, siga a arquitetura já existente do projeto e não instale dependências sem necessidade. Resultado esperado, entregar aplicações Next.js modernas, rápidas, organizadas, acessíveis, escaláveis e seguras, prontas para produção usando os recursos atuais do framework.
